# KG Schema External Reviews

Schema v3.1 was reviewed by four independent AI models across five rounds.
Full transcripts maintained separately. This directory contains the synthesis
prompt and summary of findings.

## Review Rounds
1. Gemini Pro (Round 1) — Initial design critique
2. GPT-5.2 (Rounds 1, 2, 3) — Design, synthesis, structural bugs
3. Kimi-K2.5 (Round 1) — Architecture breakthrough (derive, don't extract)
4. Grok-4 (Round 1) — Harvest architecture validation
